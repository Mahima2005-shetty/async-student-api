# Async Student Management API

A RESTful API built with FastAPI, SQLAlchemy, and SQLite for managing student records asynchronously.

## Features
- ✅ Create, Read, Update, Delete students
- ✅ Async database operations
- ✅ Request validation with Pydantic
- ✅ Interactive API documentation (Swagger UI)

## Technologies
- Python 3.9+
- FastAPI
- SQLAlchemy (async)
- Pydantic
- SQLite (aiosqlite)
